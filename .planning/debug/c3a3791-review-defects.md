# Debug Session: Review c3a3791 Follow-up Findings

## 1. Symptoms & Review Findings
1. **Finding 1 (P1): Synthetic ticks bypass daily forming-minute protection (`useChartData.ts:496–501`)**
   - Symptom: A real `seekTickTime(09:30:01)` generates a synthesized tick from the unclosed 09:30 minute bar with volume 10,000, low 99.6, close 99.6.
   - When TSLA has no raw symbol ticks, `useChartData.ts`'s `else if (latestTick ...)` branch immediately re-adds `latestTick.volume` (10,000) and adopts its synthetic low/close, completely bypassing the forming-minute protection.
2. **Finding 2 (P1): Volume reconstruction imports premarket into RTH-only daily candle (`useChartLifecycle.ts:505–510`)**
   - Symptom: When hydrating snapshot state on a 1D chart, `useChartLifecycle.ts` iterates through `masterData` and filters only by timestamp and bucket. Because PRE and REG bars share the same daily bucket, 1,000 PRE shares from 09:20 get added into `bucketMinutes`, causing daily volume to become 1,200 instead of 200 on resume.
3. **Finding 3 (P2): Convergence tests pass without inspecting real state**
   - Symptom: `rereviewProbes.test.ts` direct seek path constructed a literal expected object instead of inspecting `setData` calls on series mocks, and omitted unmounting hooks. E2E journey test conditionally checked if selectors were visible.

## 2. Red Phase Verification
- Replicated in `tests/unit/followupReviewProbes.test.ts` and `tests/codex/followup/`:
  - `data.test.ts: v42: real seek into daily opening minute must preserve zero unfinished volume` -> **FAILED** (expected 0, received 10,000).
  - `review.test.ts: v42: daily fallback volume must exclude premarket after hydration` -> **FAILED** (expected <= 200, received 1,200).
  - Both defects reproduced 100% reliably.

## 3. Root Cause Analysis
1. In `src/hooks/useChartData.ts:496-501`:
   - `latestTick` generated by `usePlaybackStore` on fallback seek carries `isSynthesized: true`, `volume: currentMinuteBar.volume`, and `close: currentMinuteBar.close`.
   - The fallback branch did not check `!latestTick.isSynthesized`. In an unclosed forming minute without raw trades, synthetic fallback ticks must not add volume or leak future prices into the forming daily candle.
2. In `src/hooks/useChartLifecycle.ts:505-513`:
   - Constituent minute aggregation did not enforce `timeframe === '1D' && !isRthBar(bar, ticker, timeframe)` or `!showEth && !isRthBar(...)`.
   - Pre-market minute bars were admitted into `bucketMinutes` for RTH-only daily charts.

## 4. Fix Strategy & Implementation
1. In `useChartData.ts:496`: Added guard `&& !(latestTick as any).isSynthesized` so synthetic fallback ticks never inject unclosed source minute volume or prices into `formingDaily`.
2. In `useChartLifecycle.ts:505`: Added `if (timeframe === '1D' && !isRthBar(bar, ticker, timeframe)) continue;` and `if (!showEth && !isRthBar(bar, ticker, timeframe)) continue;` when hydrating `bucketMinutes`, as well as enforcing RTH filtering on newly elapsed ticks for 1D timeframe.
3. In `tests/unit/rereviewProbes.test.ts`: Inspected genuine `mockPriceSeries.setData` and `mockVolumeSeries.setData` calls in Path 2, and explicitly called `hook.unmount()` across all paths.
4. In `tests/regression/journey/12-replay-convergence.spec.ts`: Hardened CONV E2E 2 to unconditionally assert switched ticker (`NVDA`), bar count, and temporal bounds.
