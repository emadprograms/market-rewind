# Requirements: Milestone v1.0 Stability Guardrails & Multi-Chart Core

## Milestone Goals
Establish a rock-solid multi-chart market replay frontend with stable viewport anchoring, group synchronization, type-safe lightweight-charts plugins, and worker-offloaded database operations.

---

## Completed Requirements

### Category 1: Viewport & Layout
- [x] **VIEW-01**: Viewport stabilization during historical data prepend without screen jumping or position loss.
- [x] **VIEW-02**: Multi-chart grid layouts with dynamic resizing and flexible panel configurations.

### Category 2: Grouping & Synchronization
- [x] **SYNC-01**: Symbol and selection grouping (A, B, C, D) across multiple charts.
- [x] **SYNC-02**: Group mount synchronization — new charts adopt active group symbol on join.
- [x] **SYNC-03**: Leader propagation — changing symbol on any grouped chart propagates to all peers.
- [x] **SYNC-04**: Clean group decoupling when unassigned or reassigned.

### Category 3: Architecture & Performance
- [x] **ARCH-01**: Monolithic `useChartLifecycle` decomposed into specialized hooks (`useChartInit`, `useChartPlugins`, `useChartViewport`, `useChartDrawings`).
- [x] **ARCH-02**: Type-safe plugin primitives for session shading, volume profiles, and drawing tools.
- [x] **ARCH-03**: Background database worker proxy for non-blocking main thread performance.

### Category 4: Testing & Guardrails
- [x] **TEST-01**: Deterministic unit tests for pixel anchor math and grouping logic.
- [x] **TEST-02**: Playwright regression test suite verifying visual stability and propagation under automated runner.
