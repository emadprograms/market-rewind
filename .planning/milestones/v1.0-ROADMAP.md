# Roadmap: Milestone v1.0 Stability Guardrails & Multi-Chart Core

## Milestone Phases

### Phase 1: Viewport Stabilization
- **Goal**: Resolve viewport jumping, preserve anchor position during historical candle prepending, and stabilize scroll state during replay.
- **Plans**: 1 plan (01-01)
- **Success Criteria**:
  1. Viewport preserves visual position without anchor shift when prepending historical bars.
  2. Infinite scroll triggers smoothly without jumpy resets.

### Phase 2: Selection & Grouping Hardening
- **Goal**: Fortify multi-chart selection, group linking (A, B, C, D), and leader-follower ticker synchronization across grouped charts.
- **Plans**: 4 plans (02-01, 02-02, 02-03, 02-04)
- **Success Criteria**:
  1. Group changes propagate immediately across all charts sharing a group identifier.
  2. Un-grouping cleanly decouples ticker updates without state contamination.
  3. Rapid ticker swaps preserve chart integrity without orphaned listeners.

### Phase 3: Stability Guardrails
- **Goal**: Implement regression harnesses and runtime stability guardrails across viewport anchors, group sync, and replay stepping.
- **Plans**: 5 plans (03-01, 03-02, 03-03, 03-04, 03-05)
- **Success Criteria**:
  1. Unit and regression tests verify viewport pixel-anchor calculations.
  2. Playwright E2E visual and functional tests verify ticker swaps and sync propagation.
  3. Automated test fixtures run headlessly with deterministic data seeds.

### Phase 4: Systemic Hardening & Hook Decomposition
- **Goal**: Decompose monolithic chart hooks, type-safe lightweight-charts plugin renderers, and offload SQLite database access to a Dedicated Web Worker.
- **Plans**: 4 plans (04-01, 04-02, 04-03, 04-04)
- **Success Criteria**:
  1. Type-safe `ChartTarget` and `ChartScope` interfaces mirror lightweight-charts internal renderer primitives.
  2. Extract `useChartInit`, `useChartPlugins`, `useChartViewport`, and `useChartDrawings` from monolithic lifecycle.
  3. Migrate SQLite / sql.js operations to asynchronous web worker (`db.worker.ts`).
