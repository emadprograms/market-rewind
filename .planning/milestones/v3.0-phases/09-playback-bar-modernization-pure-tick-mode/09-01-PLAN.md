# Phase 9: Playback Bar Modernization & Pure Tick Mode

## Plan 09-01: Remove Mode Switcher & Streamline Pure Tick Controls

### Goal
Remove the "TICK vs BAR" mode toggle pill and the BAR step size dropdown from `PlaybackBar.tsx`. Ensure `usePlaybackStore` and all transport controls (play, pause, step forward, step backward, seek, reset) operate exclusively in tick mode with smooth speed control.

### Proposed Changes

1. **`src/components/PlaybackBar.tsx`**:
   - Delete lines 92–136 (the TICK vs BAR pill toggle buttons).
   - Delete lines 210–228 (the `replayMode === 'bar'` STEP dropdown).
   - Show tick scrubber slider whenever `totalTicks > 0`.
   - Update step buttons: "Step 1 Tick Backward" and "Step 1 Tick Forward".
   - Update `togglePlay`: if paused at the end of ticks, restart from index 0.
   - Set `canPlay` to `bufferedTicks.length > 0 || masterData.length > 0`.

2. **`src/store/usePlaybackStore.ts`**:
   - Ensure `replayMode` defaults to `'tick'` and stays `'tick'`.
   - Ensure `tick()` advances by `stepCount` (default 1) within `bufferedTicks`.
   - Ensure `stepForward()` and `stepBackward()` operate cleanly on `currentTickIndex`.

3. **`tests/integration/tickReplay.test.tsx`**:
   - Update test to assert that `screen.queryByText('BAR')` is NOT in the document.
   - Assert that tick replay controls, price badges, and stepping work seamlessly without mode toggle.
