## Architectural Improvements

### 1. Zero React Re-renders During Playback
- **Before**: Every playback tick (~60fps) triggered React state updates in `useChartData` and `useChartLifecycle`, causing complete JSX re-renders, O(N) array filtering, O(N) candle resampling, and volume profile re-computations.
- **After**: State subscriptions are active only when paused. During playback, React renders are completely bypassed (0 React re-renders/sec).

### 2. O(1) Canvas Updates
- **Before**: `useChartLifecycle` called `series.setData()` with thousands of formatted bars on every frame.
- **After**: Direct store subscription in `useChartLifecycle` calls `priceSeries.update()` and `volumeSeries.update()` directly in O(1) time (< 0.02ms per frame).

### 3. Non-Blocking Viewport Interaction
- **Before**: `syncViewport` constantly called `setVisibleLogicalRange` at 60fps, fighting the user's mouse dragging and freezing interaction during playback.
- **After**: The viewport is untouched during active playback, allowing free, smooth panning and zooming.

### 4. Robust Single-Candle Prevention
- **Before**: Non-replay initial load defaulted to a 09:30 ET cutoff, clipping all data if `globalTime` was absent. API returning 1 bar was committed directly without validation.
- **After**: Cutoff defaults to `Infinity` for static loads; queries returning 1 bar automatically retry with open boundaries; lifecycle suppresses rendering while background loading is in progress.
