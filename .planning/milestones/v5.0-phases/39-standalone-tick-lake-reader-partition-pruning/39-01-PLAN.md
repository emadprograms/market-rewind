# Plan 39-01: Standalone Tick Lake Reader & Partition Pruning

## Objective
Implement a zero-dependency `TickLakeReader` class adhering to Data Harvester's Repo B Tick Lake Read Contract (`docs/contracts/repo_b_tick_lake_contract.md` v1.5.0), providing root discovery precedence, canonical symbol path encoding, filesystem partition pruning, and structured error handling.

## Context & Constraints
- **Zero data-harvester imports**: Must not import anything from `src.` or `data-harvester`. Uses only standard Python library and `duckdb`.
- **Safe symbol encoding**: Strictly `[A-Za-z0-9_-]`. Period (`.`) and slash (`/`) must be uppercase percent-encoded byte-by-byte (`BRK.B` -> `BRK%2EB`).
- **Partition pruning**: Query only `ticks/symbol=<ENCODED_SYMBOL>/date=<YYYY-MM-DD>/*.parquet`. Never scan root or non-data trees (`_staging/`, `_maintenance/`, `_control/`).
- **Maintenance guard**: Must check for `<lake_root>/_maintenance/in_progress.json` and raise `LakeMaintenanceInProgressError`.

## Tasks

### Task 1: Create `backend/streaming_service/tick_lake_reader.py`
1. Define structured exception hierarchy:
   - `LakeReaderError(Exception)`
   - `LakeUnavailableError(LakeReaderError)`
   - `LakeCorruptedMetadataError(LakeReaderError)`
   - `LakeIncompatibleSchemaError(LakeReaderError)`
   - `LakeMaintenanceInProgressError(LakeReaderError)`
2. Implement symbol encoder:
   - `SAFE_SYMBOL_CHARS = frozenset("ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789_-")`
   - `encode_symbol(symbol: str) -> str`: byte-by-byte uppercase `%XX` encoding for characters not in safe set.
   - `decode_symbol(encoded: str) -> str`: URL-decoding back to canonical symbol.
3. Implement `TickLakeReader` class:
   - `__init__(lake_root: Optional[Union[str, Path]] = None)`:
     Resolution precedence: explicit argument -> `TICK_LAKE_ROOT` env var -> `DATA_DIR/tick_lake` -> `ROOT_DIR.parent / "data-harvester" / "data" / "tick_lake"` -> `/Volumes/Micron-E 0256 A/data-harvester/data/tick_lake`.
   - `validate_lake() -> None`:
     Validates root path exists and is a directory (raises `LakeUnavailableError`).
     Reads and validates `lake.json` (raises `LakeCorruptedMetadataError` on missing/invalid JSON, or `LakeIncompatibleSchemaError` if `format != "tick_lake"` or `schema_version not in compatible_versions`).
   - `is_maintenance_in_progress() -> bool`:
     Checks if `_maintenance/in_progress.json` exists.
   - `resolve_files(symbol: str, start_date: date, end_date: date) -> List[str]`:
     Prunes partitions by inspecting `ticks/symbol={encode_symbol(symbol.upper())}/`.
     Extracts date from `date=YYYY-MM-DD` directory names; matches `start_date <= dir_date <= end_date`.
     Collects and sorts `*.parquet` files. Returns `[]` immediately if symbol directory is missing or no files match.
