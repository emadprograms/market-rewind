## Boundary honoured

The collector was **read and patched, never executed**. No broker session was created, no
credentials were loaded, no trading mutation was sent. The repair tests assert this:
`--calibrate` was invoked only as a crash probe and proved the collector no longer dies on an
undefined delay; credential loading is unit-tested through `loadDemoCredentials()` directly.

## Defects found and fixed

1. **`fillOrder` never resolved a position for exit fills** (found in Phase 44 testing, fixed there).
2. **Request bounds were initialised in `setCredentials()`**, but the clock probe issues requests
   before authenticating → `AbortSignal.timeout(undefined)` threw on every `--calibrate` run.
   Bounds moved to the constructor.
3. **The credential loader accepted a generic `CAPITAL_API_KEY`**, which can resolve to live
   credentials. Now only demo-specific names are accepted.
4. `--calibrate` is credential-free by design, so a test that used it to prove credential scope was
   replaced with a direct unit test of the loader.
