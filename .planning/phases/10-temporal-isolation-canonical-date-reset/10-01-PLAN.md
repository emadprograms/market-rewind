# Phase 10: Temporal Isolation & Canonical 9:20 AM ET Date Reset

## Plan 10-01: Canonical 9:20 AM ET Anchor, Strict Date Bounding, and Micro-Tick Synthesis

### Goal
Guarantee that selecting any day or resetting to open always anchors the replay cursor at exactly 9:20 AM Eastern Time of that day, strictly bounds all data queries so future data cannot leak, and backfills micro-ticks so every day has tick replay.

### Proposed Changes

1. **`src/hooks/useMarketSimulator.ts`**:
   - Bounded historical fetch: pass `endTime: `${selectedDate} 23:59:59`` to `streamingClient.getCandles`.
   - In `loadMarketData`: calculate `targetTimeStr = getUtcTimeFromEt(selectedDate, entryTime)` and set `currentTime` to `targetMs`.
   - In `handleResetToOpen`: set `currentTime` to `targetMs`, seek ticks to `targetMs`, and pause.

2. **`src/hooks/useChartData.ts`**:
   - Pass `endTime: `${selectedDate} 23:59:59`` to `streamingClient.getCandles`.
   - Update `filteredData`:
     - For 1D: `d.time <= endOfReplayDay` (where `endOfReplayDay` is 23:59:59.999 UTC of `globalTime`).
     - For intraday: `d.time < currentBucketStartMs` (all bars before the current forming bucket).
     - When `currentTick` is not active: `d.time <= globalTime`.

3. **`src/App.tsx`**:
   - In `loadStreamingTicks`:
     - Calculate `startTime = getUtcTimeFromEt(selectedDate, '09:20')`.
     - Calculate `endTime = `${selectedDate} 23:59:59``.
     - Fetch ticks from `streamingClient.getTicks(sessionTicker, { startTime, endTime, limit: 100000 })`.
     - If raw ticks start after 9:20 AM (e.g. 13:28 UTC): fetch 1m candles for 13:20 to 13:28, synthesize micro-ticks using `synthesizeTicksFromBars`, and prepend them.
     - If no raw ticks exist for that day: fetch 1m candles for that day from 9:20 AM onwards, synthesize micro-ticks, and buffer them.
     - Always set `usePlaybackStore.setCurrentTime(targetMs)` and `seekTickTime(targetMs)`.

### Verification
- Verify that date reset places cursor at 9:20 AM ET.
- Verify that no future bars exist on the chart.
