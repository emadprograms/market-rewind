# Phase 11: Real-Time Tick-by-Tick Candle Forming & Playback Engine

## Plan 11-01: Real-Time Tick Forming on All Timeframes and Smooth Playback Loop

### Goal
Ensure that clicking PLAY on a 5-minute (or any) chart visibly updates the forming candle's High, Low, Close, and Volume in real time with each incoming tick, and update `PlaybackManager.tsx` to handle all playback speeds (0.5x to 100x) smoothly.

### Proposed Changes

1. **`src/components/PlaybackManager.tsx`**:
   - Optimize timer loop: at low/medium speeds (0.5x to 10x), run `tick(1)` at `1000 / playbackSpeed` ms.
   - At high speeds (25x to 100x), cap timer at ~30ms (~33fps) and step `Math.round(playbackSpeed / 33)` ticks per interval to prevent browser thread throttling.

2. **Forming Candle Synthesis Verification**:
   - Verify that `useChartData.ts` computes the forming candle using `buildCandleFromTickSlice` from the current bucket's ticks in `bufferedTicks`.
   - Verify that lightweight-charts updates the forming candle via `update()` without flicker.
   - When transitioning into a new bucket (e.g. at :05, :10, :15, :20, :25), the completed candle is appended and the new candle starts forming.

### Verification
- Unit test for slice-based candle aggregation across multiple ticks.
- Verification of PlaybackManager interval and tick stepping.
