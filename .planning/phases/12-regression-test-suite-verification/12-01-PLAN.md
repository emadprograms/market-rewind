# Phase 12: Regression Test Suite & Verification

## Plan 12-01: Automated Regression Tests for Pure Tick Playback, Date Reset, and Temporal Isolation

### Goal
Provide rigorous automated regression tests in `tests/regression/replay/tickReplayDateReset.test.ts` covering the canonical 9:20 AM ET reset, strict future data exclusion, real-time 5-minute candle updates from ticks, micro-tick synthesis, and streamlined playback bar controls.

### Proposed Test Cases
1. `Canonical 9:20 AM ET Reset`: Verifies that date switching or reset anchors `currentTime` to 9:20 AM ET (13:20:00 UTC) with paused state.
2. `Temporal Isolation on Daily Charts`: Verifies that 1D historical bars after the selected date are strictly excluded.
3. `Temporal Isolation on Intraday Charts`: Verifies that bars after the current replay cursor and completed historical bars in the current bucket are excluded.
4. `Live 5-Minute Candle Forming`: Verifies that sequential ticks dynamically update Open, High, Low, Close, and Volume for the forming 5-min candle.
5. `Bucket Boundary Rollover`: Verifies that crossing the 5-min mark closes the formed candle and starts a new candle cleanly.
6. `Micro-Tick Synthesis`: Verifies that `synthesizeTicksFromBars` generates valid intraminute ticks.
7. `Pure Tick UI Verification`: Verifies absence of TICK/BAR toggle and presence of speed, scrub, and step controls.

### Verification
- Run `npm test tests/regression/replay/tickReplayDateReset.test.ts`.
- Run full project test suite `npm test` (all suites must pass 100% green).
