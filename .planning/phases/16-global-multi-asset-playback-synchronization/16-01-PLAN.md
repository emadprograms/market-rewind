# Plan 16-01: Global Multi-Asset Playback Synchronization

## Objective
Implement universal multi-asset synchronized playback across all open charts, group members, and dynamic ticker selections:
1. **Universal Replay Clock (`SYNC-01`)**: Playback store maintains a global timeline (`currentTime`) coordinating all charts simultaneously.
2. **Multi-Ticker Tick Transport (`SYNC-02`)**: Playback store buffers and indexes multi-asset tick streams (`ticksBySymbol` and `latestTickBySymbol`), with chronologically interleaved replay ticks.
3. **Multi-Chart Real-Time Candle Forming (`SYNC-03`)**: Every visible chart dynamically computes forming candles and last prices from its respective symbol ticks up to `currentTime`.
4. **Group & Selection Stream Sync (`SYNC-04`)**: When a chart changes symbol or adopts a group ticker (e.g. switching to AMD), it immediately streams ticks and dynamically synchronizes to `currentTime`.

## Implementation Tasks
1. **`src/store/usePlaybackStore.ts`**:
   - Add `ticksBySymbol: Record<string, MarketTick[]>` and `latestTickBySymbol: Record<string, MarketTick>`.
   - Update `setBufferedTicks` to index ticks by symbol and initialize `latestTickBySymbol`.
   - Add `addSymbolTicks(symbol, ticks)` to dynamically ingest and merge tick streams for new symbols.
   - Update `tick`, `stepForward`, `stepBackward`, `seekTickIndex`, `seekTickTime` to keep `latestTickBySymbol` accurate for all assets.
2. **`src/App.tsx`**:
   - In `loadStreamingTicks`, query ticks for all active workspace tickers (e.g. AAPL, AMD, SPY) in parallel and interleave them chronologically into `setBufferedTicks`.
3. **`src/hooks/useChartData.ts`**:
   - Subscribe to `latestTickBySymbol[ticker]` and `ticksBySymbol[ticker]`.
   - Calculate forming candles using `ticker`'s symbol ticks within the current bucket up to `globalTime`.
   - Dynamically load ticks via `addSymbolTicks` if a chart switches to a symbol not yet buffered.
4. **Verification**:
   - Run Vitest suite: `npm test`
   - Run Playwright regression suite: `npx playwright test`
   - Verify `TEST-02`, `TEST-03`, `SYNC-01`, `SYNC-02`, `SYNC-03`, `SYNC-04`.
