# Phase 22-01 Plan: Event-Driven Playback Ingestion & Canonical Candle Aggregation

## Objective
Fix volume overcounting, trade omission, and premarket fallback defects by introducing event-aware tick tracking, intra-frame trade aggregation, empty history first-candle startup, multi-symbol cursor stability, and strict ETH filtering during active playback.

## Requirements Covered
- **INGEST-01**: Event-Deduplicated Volume & High/Low Aggregation
- **INGEST-02**: Elimination of Fallback Volume Compounding
- **INGEST-03**: First-Candle Initialization on Empty History
- **INGEST-04**: Multi-Symbol Ingestion Cursor Stability
- **INGEST-05**: Strict ETH / Extended Hours Playback Filtering

## Proposed Changes

### 1. `src/hooks/useChartLifecycle.ts` (Active Playback Subscriber)
- Implement event-aware tick consumption:
  - Maintain `lastConsumedTickRef` / `lastConsumedTickTimeRef` for the active ticker.
  - When replay clock advances, query all elapsed ticks for the symbol in `state.ticksBySymbol[sym]` between the last consumed timestamp and `state.currentTime`.
  - If `state.ticksBySymbol[sym]` is absent or single-tick, guard against recounting: if `lastConsumedTickRef.current === tick`, skip volume addition.
  - Aggregate all intermediate trades in the frame into `high = Math.max(...)`, `low = Math.min(...)`, `close = lastTick.price`, and sum incremental volume.
- Implement first-candle creation when history is empty (`!lastCandleRef.current`):
  - Directly synthesize and paint the first forming candle using the arriving tick, updating `lastCandleRef.current`.
- Implement strict `showEth` filtering:
  - If `!showEth`, check `isRthTick(tick, ticker)` and skip premarket ticks completely during live playback.
- Handle fallback ticks gracefully:
  - When tick is synthetic from fallback minute bar, do not repeatedly add the entire minute's volume on every frame.

### 2. `src/store/usePlaybackStore.ts`
- In `addSymbolTicks`:
  - After sorting `combined`, recompute `currentTickIndex` so it preserves the current tick/time cursor identity.
- In `advanceSimulationTime`:
  - Mark fallback ticks with `isSynthesized: true` so the consumer knows not to compound volume.

### 3. `src/hooks/useChartData.ts`
- Fix higher timeframe reconstruction (5m, 15m, 1h) to prevent future candle leakage:
  - When synthesizing higher-timeframe forming candles, do not use `localMasterData` when replay time is at the bucket open boundary; use elapsed ticks or `masterData` with open-only prices when `bMs === effectiveCutoff`.
  - Remove SPY-only special cases so all symbols use consistent aggregation rules.
