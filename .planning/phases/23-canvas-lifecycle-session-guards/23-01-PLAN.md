# Phase 23-01 Plan: Canvas Lifecycle Reconciliation, Session Guards & Tape Filtering

## Objective
Resolve canvas history omission, symbol-switch price leakage, out-of-order session overwrites, and multi-symbol tape trade pollution.

## Requirements Covered
- **RENDER-01**: Comprehensive Historical Reconciliation (DIAG 3)
- **RENDER-02**: Atomic Symbol Switching (DIAG 8)
- **RENDER-03**: Session Generation & Request Cancellation (DIAG 11)
- **RENDER-04**: Time & Sales Symbol Filtering (Tape Isolation)

## Key Technical Work
1. **Incremental vs Prepend Check in `useChartLifecycle` (RENDER-01)**:
   - When new data has older prepended bars with the same last timestamp as the currently displayed chart data, trigger full `setData()` rather than treating it as an incremental update.
2. **Atomic Symbol Switching in `useChartData` (RENDER-02)**:
   - Track `loadedTickerRef.current`. When symbol changes, bypass equality checks on cached arrays so new ticker prices immediately replace the old ticker's candles even when timestamp domains match.
3. **Session Generation Tokens in `useMarketSimulator` (RENDER-03)**:
   - Maintain a monotonic `sessionGenRef` token. On date changes, discard stale network responses from previous dates, preventing delayed responses from overwriting the clock.
4. **Time & Sales Multi-Symbol Isolation (RENDER-04)**:
   - In `TimeAndSales.tsx`, strictly filter executed ticks by `displaySymbol`.
   - In `App.tsx`, pass the active chart's symbol badge to `TimeAndSales` so selecting any chart focuses the tape on that symbol.
