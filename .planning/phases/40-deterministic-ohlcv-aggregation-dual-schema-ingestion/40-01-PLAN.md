# Plan 40-01: Deterministic OHLCV Aggregation & Dual Schema Ingestion

## Objective
Implement high-performance in-memory DuckDB query capabilities in `TickLakeReader`, delivering deterministic OHLCV candlestick aggregation (`time_bucket()`) with `(timestamp, ingest_id)` tie-breaking, dual schema support (Schema v1 and Schema v2), and strict Regular Trading Hours (RTH) filtering for daily bars.

## Context & Constraints
- **In-Memory Concurrency**: Connections must use `duckdb.connect(":memory:")` with `threads = 4`, `max_memory = '2GB'`, and `TimeZone = 'UTC'`.
- **Hive Partitioning Guard**: Must specify `read_parquet(?, hive_partitioning=false)` to avoid schema merge collisions with dictionary-encoded `symbol` columns.
- **Dual Schema**: Existing Parquet files on disk use Schema v1 (`price`, `volume`, `bid`, `ask`). New rows store `bid_price` and `ask_price`. Resampling must handle both gracefully using `COALESCE(price, bid_price)`.
- **RTH Policy**: Daily (`1d`) candles must strictly include only Regular Trading Hours (`session = 'REG'`).

## Tasks

### Task 1: Add In-Memory DuckDB Query Methods to `TickLakeReader`
1. Add `query_candles` to `TickLakeReader`:
   - Arguments: `symbol: str, timeframe: str = "1m", start_time: Optional[str] = None, end_time: Optional[str] = None, limit: int = 15000, direction: Optional[str] = None, session: Optional[str] = None`.
   - Parse ISO timestamp strings to UTC event dates to prune partition files via `resolve_files`.
   - If no files found, return `[]`.
   - Execute in-memory DuckDB query:
     ```sql
     SELECT
         time_bucket(INTERVAL '{interval}', timestamp) AS bucket_time,
         symbol,
         arg_min(coalesce(price, bid_price), (timestamp, ingest_id)) AS open,
         max(coalesce(price, bid_price)) AS high,
         min(coalesce(price, bid_price)) AS low,
         arg_max(coalesce(price, bid_price)) AS close,
         sum(coalesce(volume, 1.0)) AS volume,
         count(*) AS tick_count
     FROM read_parquet(?, hive_partitioning=false)
     WHERE {where_conditions}
     GROUP BY bucket_time, symbol
     ORDER BY bucket_time {sort_dir}
     LIMIT {limit}
     ```
   - For `timeframe == '1d'`, automatically enforce `session = 'REG'`.
   - Catch `duckdb.IOException` (mid-query compaction file replacement), re-resolve partition files once, and retry before raising.
2. Add `query_ticks` to `TickLakeReader`:
   - Arguments: `symbol: str, start_time: Optional[str] = None, end_time: Optional[str] = None, limit: int = 10000, offset: int = 0, direction: str = "asc"`.
   - Query raw tick columns sorted by `timestamp {direction}, ingest_id {direction}`.
   - Return normalized dictionaries with `time`, `symbol`, `price`, `volume`, `bid`, `ask`, `source`, `session`.
