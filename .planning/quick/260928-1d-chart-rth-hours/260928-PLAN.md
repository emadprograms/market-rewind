# Quick Task: 1D Chart RTH Hours Filtering

## Problem Statement
Currently, Market Rewind uses data throughout the entire 24h day (including pre-market and after-hours/post-market sessions) when building the 1D chart:
1. In `src/hooks/useChartData.ts`, `filteredData` explicitly bypasses session filtering for `timeframe === '1D'`, allowing all ETH bars through even when `showEth` is false.
2. In `src/hooks/useChartData.ts`, the forming daily candle filters `todayBars` starting at midnight (`00:00:00 ET`), taking pre-market bars as the day's open and incorporating post-market price movements and ticks into today's daily bar.
3. In `src/lib/resampling.ts`, `resampleData(data, '1D')` aggregates all intraday bars into the daily candle without checking for RTH session, polluting daily high, low, close, and volume with extended-hours data.
4. In `src/lib/candleSynthesizer.ts`, `applyTickToCandles` and `buildCandlesFromTicks` apply pre-market and post-market ticks to 1D candles.
5. In `backend/streaming_service/duckdb_client.py`, dynamic daily aggregation (`time_bucket(INTERVAL '1 day', ...)` across `ticks` and `market_data`) includes `PRE` and `POST` sessions rather than restricting to RTH (`session = 'REG'`).

## Target Behavior
- The 1D chart must strictly represent Regular Trading Hours (09:30 AM - 04:00 PM Eastern Time):
  - **Open price**: The open price of the 09:30 AM RTH session (not pre-market open at 04:00 AM).
  - **Close price**: The close price of the 16:00 PM RTH session (not after-hours close at 20:00 PM).
  - **High & Low**: The highest and lowest prices reached during RTH (ignoring pre-market and post-market spikes).
  - **Volume**: The sum of volume traded during RTH only.
- In replay / simulation:
  - Before 09:30 AM ET: No forming daily candle for today exists yet (only historical completed daily candles).
  - Between 09:30 AM and 16:00 PM ET: Daily candle forms and updates in real-time from RTH bars and ticks.
  - After 16:00 PM ET: Daily candle is finalized at the 16:00 close; subsequent post-market ticks/bars do not alter the 1D candle.

## Execution Plan

### Task 1: RTH Session Detection Utilities (`src/lib/timezones.ts`)
- Implement and export `isRthBar(bar, ticker)` to test if a bar belongs to RTH (evaluating `session === 'REG'` / `session === 'RTH'` or timestamp-based session calculation).
- Implement and export `isRthTick(tick, ticker)` to test if a tick belongs to RTH.

### Task 2: RTH-Only Daily Resampling & Candle Synthesis (`src/lib/resampling.ts` & `src/lib/candleSynthesizer.ts`)
- In `src/lib/resampling.ts`:
  - When `timeframe === '1D'`, filter out bars that are not in RTH (`if (!isRthBar(bar)) return;`).
  - Set the resulting daily bar's session to `'REG'`.
- In `src/lib/candleSynthesizer.ts`:
  - In `applyTickToCandles`: if `timeframe === '1D'` and `!isRthTick(tick)`, return `candles` unchanged.
  - In `buildCandlesFromTicks`: if `timeframe === '1D'`, skip ticks that are not RTH.

### Task 3: Hook Isolation for 1D Playback & Forming Candle (`src/hooks/useChartData.ts`)
- In `filteredData`:
  - When `timeframe === '1D'`, filter `localMasterData` strictly with `isRthBar(d, ticker)`. Do not bypass session filtering.
- In `chartData` forming daily candle:
  - Define `rthOpenMs = startOfTodayMs + 9.5 * 3600000` (09:30 ET) and `rthCloseMs = startOfTodayMs + 16 * 3600000` (16:00 ET).
  - Restrict `todayBars` strictly to `bMs >= rthOpenMs && bMs <= Math.min(effectiveCutoff, rthCloseMs) && isRthBar(b, ticker)`.
  - Only update `formingDaily` with `latestTick` if `effectiveCutoff >= rthOpenMs && effectiveCutoff <= rthCloseMs && isRthTick(latestTick, ticker)`.

### Task 4: Backend DuckDB 1D RTH Filtering (`backend/streaming_service/duckdb_client.py` & `server.py`)
- In `query_candles`: When `timeframe.lower() in ("1d", "1 day")`, append `(upper(session) = 'REG' OR session = 'RTH')` to `where_clauses`.
- In `_query_historical_candles`: When `timeframe.lower() in ("1d", "1 day")`, append `(upper(session) = 'REG' OR session = 'RTH')` to `where_clauses`.
- Support optional `session` parameter in `handle_candles` in `server.py`.

### Task 5: Comprehensive Unit & Regression Tests
- Update `tests/unit/chartIntegrity.test.ts` to assert that 1D daily resampling excludes `POST` bars.
- Create new test file `tests/unit/dailyRthChart.test.ts`:
  - Resampling intraday bars with PRE, REG, POST sessions into 1D: asserts open is RTH open, close is RTH close, volume is RTH-only, high/low ignore extended-hours extremes.
  - Verifies `applyTickToCandles` rejects PRE and POST ticks for 1D.
  - Verifies forming candle window boundaries (09:30 - 16:00 ET).
  - Verifies crypto/UTC tickers behave as expected.
- Add backend test in `backend/streaming_service/tests/test_duckdb_service.py` verifying 1D candles exclude non-RTH ticks.
- Run all test suites (`npx vitest run` and `PYTHONPATH=. pytest`).
