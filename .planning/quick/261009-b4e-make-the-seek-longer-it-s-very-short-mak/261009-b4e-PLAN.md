# Quick Task 261009-b4e: Extend Playback Seek Bar and Mark Timestamps

## Problem Statement
The bottom playback scrubber in `PlaybackBar.tsx` was constrained with `maxWidth: '420px'` inside a bar spanning the full screen width. With the time display label, jump input, and tick counter sharing that 420px constraint, the slider `<input type="range">` itself was restricted to ~140px, making fine-grained seeking across full trading days (6.5+ hours) difficult and inaccurate. Additionally, the seek track lacked timestamp marks along its timeline, making it hard to see where hours or session milestones fall.

## Requirements
1. **Extend Seek Bar**: Remove restrictive `maxWidth: '420px'` on the scrubber container, allowing it to flex (`flex: 1`, `minWidth: '240px'`) and occupy all available space in `PlaybackBar.tsx` between the transport controls and speed/tape controls.
2. **Mark Timestamps Along Seek Track**:
   - Compute appropriate intervals (e.g., hourly for typical sessions) across `[minTime, maxTime]`.
   - Render timestamp marks and tick lines along the seek track (session start, intermediate hours/intervals, session end) in the ticker's timezone.
   - Attach `<datalist id="playback-time-markers">` to `<input type="range">` for native browser tick alignment.
3. **Interactive Timestamp Marker / Hover Preview**:
   - Provide a hover tooltip showing the exact timestamp at the cursor's scrub position when moving across the seek bar.
4. **Preserve Existing Elements and Selectors**:
   - Keep `playback-time-slider`, `playback-time-label`, `time-jump-input`, `tick-counter` test IDs and event semantics intact.
5. **Unit Tests**:
   - Verify timeline marks rendering, expanded layout styling, and hover/marker behavior.

## Tasks
1. **Task 1: Update PlaybackBar Seek Component & Styles** (`src/components/PlaybackBar.tsx`)
   - Remove `maxWidth: 420px`, make seek container `flex: 1` with responsive layout.
   - Implement `computeTimelineMarks` helper returning structured timestamp marks.
   - Render timestamp marks with tick marks, start/end labels, and datalist.
   - Add hover timestamp preview marker.
2. **Task 2: Add Tests for Extended Seek & Marked Timestamps** (`tests/unit/playbackBarExtendedSeek.test.tsx`)
   - Test timeline marks generation across session bounds.
   - Test rendered timestamp markers and labels.
   - Test slider expanded container properties.
3. **Task 3: Run Full Test Suite and Verification**
   - Verify all existing and new tests pass cleanly.
