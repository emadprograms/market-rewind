## 4. Cross-Phase Integration & E2E Flows

Integration checker validated the following 4 core application flows:
1. **DuckDB Backend $\longleftrightarrow$ `streamingClient.ts`**:
   - `/api/status`, `/api/ticks`, and `/api/candles` strictly query `streaming.duckdb`.
   - `/api/stream/tape` isolated solely to Time & Sales drawer.
2. **`App.tsx` $\longleftrightarrow$ `usePlaybackStore`**:
   - `loadStreamingTicks` queries active workspace tickers concurrently, interleaves them chronologically, and loads into `bufferedTicks`.
   - Holiday/weekend sessions with 0 ticks cleanly handled by disabling playback and anchoring to canonical 9:20 AM ET.
3. **`usePlaybackStore` $\longleftrightarrow$ `useChartData`**:
   - Universal replay clock (`currentTime`) advances continuously.
   - Each chart instance dynamically forms candles for its own symbol up to `globalTime` using `buildCandleFromTickSlice`.
4. **Group & Ticker Switching $\longleftrightarrow$ `useWorkspaceStore` $\longleftrightarrow$ `useChartData`**:
   - Charts dynamically adopt group symbols and fetch missing symbol ticks on-demand via `addSymbolTicks` without session restarts.
